# Lazismu Kabupaten Batu Bara

## Menjalankan situs

1. Buka folder proyek ini.
2. Jalankan `run-server.bat`.
3. Jalankan `setup-https.bat` sekali untuk membuat sertifikat HTTPS lokal.
4. Buka `https://localhost:4173`.

## Memperbarui konten

- Login pengurus menggunakan ID `26112026`.
- Password awal juga `26112026`.
- Klik tombol roda gigi/`Kelola` untuk mengubah judul, deskripsi, dan foto utama.
- Unggah dokumentasi melalui bagian `Jejak kebaikan`.
- Perubahan disimpan ke `config.json` dan `documentation.json` di server.
- Untuk pembaruan versi, ganti berkas pada folder ini lalu jalankan kembali `run-server.bat`.
